# Mixtapes

Use this file as a quick reminder of what a good stored tape should include.

## Minimum Viable Tape

- Title
- One-sentence purpose
- Use case
- Vibe or arc
- Runtime target
- Ordered tracks
- Short share note

## Good Tape Behaviors

- The first track sets social permission.
- The midpoint should change something, even subtly.
- The ending should feel chosen, not accidental.
- Discovery tracks should be anchored by at least some familiar context when the audience is mixed.
- If the tape is for an event, sequence for the room, not just the curator's taste.

## Library Guidance

- Prefer linking a mix to songs that already exist in the library.
- Only create a new song record when the track is genuinely new to the library.
- If a song is reused across many mixes, enrich the shared song record instead of copying edits everywhere.

## Share Strategy

When users want to share a tape in phase one:

- Show the title, arc, and track order.
- Link out to MusicBrainz, YouTube search, or other legal destinations.
- Keep the page attractive and legible.
- Make it obvious that this is a curated tape, not a hosted audio platform.
